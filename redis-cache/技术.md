# Redis 缓存与数据结构 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 客户端 | redis-cli / 语言 SDK | 各类语言 |
| 数据结构 | String / Hash / ZSet | 按场景选型 |
| 分布式 | Redisson | 锁与对象 |
| 可视化 | ARDM / RedisInsight | 可视管理 |
| 持久化 | RDB / AOF | 数据安全 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **五大结构**：String / Hash / List / Set / ZSet
- **过期与淘汰**：TTL 与 LRU
- **持久化**：RDB 与 AOF 取舍
- **分布式锁**：正确实现与坑

## 学习路径

1. 先用 Redis 做缓存
2. 再学数据结构应用
3. 最后做分布式锁与限流
