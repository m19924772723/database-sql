# Redis 缓存与数据结构 · 简介

> Redis 缓存、数据结构与分布式应用

## 能做什么

- 缓存加速与失效策略
- 分布式锁与限流
- 计数器与排行榜
- 轻量消息队列
- 会话与令牌存储

## 适合的项目

- **缓存加速**：热点数据
- **排行榜**：实时排序
- **分布式协调**：锁与限流

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Redis（已运行 :6379）、Another Redis Desktop Manager、RedisInsight
- 注意：本机 Redis 已在运行；注意持久化配置与内存上限

## 快速开始

```bash
redis-cli set k v
redis-cli get k
redis-cli --scan --pattern "*"
```
