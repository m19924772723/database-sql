# Redis 缓存与数据结构 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 缓存

- **读写缓存**：热点加速
- **失效策略**：TTL / 主动删
- **防穿透**：空值缓存 / 布隆

## 结构应用

- **计数器**：原子自增
- **排行榜**：ZSet 排序
- **去重**：Set / HyperLogLog

## 分布式

- **分布式锁**：互斥访问
- **限流**：令牌桶 / 滑窗
- **延迟队列**：ZSet 实现

## 运维

- **持久化**：RDB / AOF
- **内存管理**：淘汰策略
- **监控**：慢日志与内存

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
