# MySQL 建模与 SQL 开发 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 引擎 | InnoDB | 事务与行锁 |
| 工具 | DBeaver / Navicat | 可视化客户端 |
| 优化 | EXPLAIN / 慢查询日志 | 定位瓶颈 |
| 脚本 | SQL 迁移脚本 | 结构演进 |
| 备份 | mysqldump / xtrabackup | 数据安全 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **范式与反范式**：设计取舍
- **索引原理**：B+ 树与最左前缀
- **事务隔离**：MVCC 与锁
- **执行计划**：EXPLAIN 解读

## 学习路径

1. 先设计一个业务表
2. 再学索引与优化
3. 最后做备份与运维脚本
