# MySQL 建模与 SQL 开发 · 简介

> MySQL 表结构设计、索引优化与 SQL 开发

## 能做什么

- 表结构设计与范式
- 索引与查询优化
- 事务与并发控制
- 视图 / 存储过程
- 备份与恢复

## 适合的项目

- **业务库设计**：系统底层
- **SQL 练习**：技能提升
- **性能调优**：慢查询治理

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：MySQL 8.0.18（已运行 :3306）、SQL 客户端、DBeaver（可选）
- 注意：本机 MySQL 已在运行，可直接连；生产务必做备份

## 快速开始

```bash
mysql -u root -p -e "CREATE DATABASE demo"
mysql -u root -p demo < schema.sql
mysql -u root -p demo -e "SELECT * FROM t LIMIT 5"
```
