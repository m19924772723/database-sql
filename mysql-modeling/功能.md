# MySQL 建模与 SQL 开发 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 建模

- **表设计**：字段与类型
- **关系**：外键与关联
- **范式**：规范化取舍

## 优化

- **索引**：合理建索引
- **慢查询**：定位与重写
- **分页**：深分页优化

## 运维

- **备份恢复**：定期备份
- **主从**：读写分离
- **分区归档**：冷数据

## 安全

- **权限**：最小权限
- **审计**：操作日志
- **脱敏**：敏感字段

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
