# SQL — 数据库开发

**定位**：关系型数据库建模、查询、存储过程、数据迁移

**本机状态**：✅ 可直接开发

**工具链**：MySQL 8.0.18（:3306 运行中）、SQLite 3.50.6；Redis（:6379 运行中）

**建议技术栈**：MySQL、SQLite、SQL 脚本

**注意**：无 PostgreSQL / SQL Server；Redis 为非关系型键值库
