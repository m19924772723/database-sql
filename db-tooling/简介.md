# 数据库工具与管理脚本 · 简介

> 数据库管理、备份与巡检脚本

## 能做什么

- 自动备份与校验
- 数据字典生成
- 巡检与告警
- 数据脱敏导出
- 批量 SQL 执行

## 适合的项目

- **运维自动化**：备份巡检
- **数据治理**：字典与脱敏
- **安全合规**：权限与审计

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：mysqldump / SQL 客户端、Python / Node 驱动、DBeaver
- 注意：备份脚本务必先验证可恢复，再交给定时任务

## 快速开始

```bash
mysqldump -u root -p --databases demo > backup.sql
python inspect_db.py --host 127.0.0.1
# 生成巡检报告
```
