# 数据库工具与管理脚本 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 备份 | mysqldump / xtrabackup | 逻辑 / 物理 |
| 客户端 | DBeaver / mycli | 可视与命令行 |
| 脚本 | Python / Node 驱动 | 自动化 |
| 巡检 | SQL 指标采集 | 健康度 |
| 调度 | 计划任务 | 周期执行 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **备份策略**：全量 + 增量 + 异地
- **恢复演练**：备份不可恢复等于没有
- **巡检指标**：连接数、慢查询、空间
- **数据脱敏**：敏感字段处理

## 学习路径

1. 先写一个备份脚本
2. 再做巡检与字典
3. 最后加调度与告警
