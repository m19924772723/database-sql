# ETL 数据管道 · 简介

> 数据抽取-转换-加载（ETL）管道搭建

## 能做什么

- 多源抽取
- 清洗与转换
- 批量加载
- 调度编排
- 数据质量校验

## 适合的项目

- **数据仓库**：分层建设
- **报表数据准备**：预聚合
- **系统间同步**：数据搬运

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Python / SQL、DataX / SeaTunnel（可选）、Airflow / dbt（可选）
- 注意：单机可跑轻量管道；编排工具较重，可按需引入

## 快速开始

```bash
pip install pandas sqlalchemy
python etl.py --date 2026-10-09
# 输出同步日志
```
