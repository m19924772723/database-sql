# ETL 数据管道 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 抽取 | pandas / 驱动 | 多源连接 |
| 转换 | SQL / pandas | 清洗计算 |
| 加载 | 批量写入 | 事务保证 |
| 编排 | Airflow / cron | 依赖调度 |
| 质量 | 校验规则 | 一致性 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **分层建模**：ODS / DWD / DWS / ADS
- **增量与全量**：策略选择
- **幂等与重跑**：可重复执行
- **数据质量**：行数、主键、空值

## 学习路径

1. 先做一个两表同步
2. 再抽成可配置管道
3. 最后加调度与质量校验
