# ETL 数据管道 · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · 两表同步

- **目标**：跑通
- **产出**：一次 ETL 作业

- [ ] 连接源与目标
- [ ] 抽取加载
- [ ] 校验行数

## 阶段二 · 转换清洗

- **目标**：数据可用
- **产出**：清洗后的表

- [ ] 字段映射
- [ ] 去重补全
- [ ] 派生指标

## 阶段三 · 增量与重跑

- **目标**：可持续
- **产出**：增量管道

- [ ] 水位线
- [ ] 幂等重跑
- [ ] 日志留痕

## 阶段四 · 编排质量

- **目标**：可交付
- **产出**：带调度与校验的管道

- [ ] 调度编排
- [ ] 质量校验
- [ ] 失败告警
