# SQLite 嵌入式应用 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 嵌入

- **单文件**：便携易备份
- **零运维**：无需服务
- **跨平台**：多语言驱动

## 查询

- **标准 SQL**：子查询与窗口
- **JSON 支持**：JSON1 扩展
- **视图**：逻辑封装

## 检索

- **FTS5**：全文搜索
- **分词**：自定义分词
- **高亮**：结果标注

## 迁移

- **版本表**：结构演进
- **备份**：文件复制 / VACUUM INTO
- **导入导出**：CSV / SQL

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
