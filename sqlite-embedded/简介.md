# SQLite 嵌入式应用 · 简介

> 用 SQLite 做零运维的嵌入式数据库应用

## 能做什么

- 单文件数据库应用
- 本地数据存储
- 全文检索（FTS5）
- 与脚本 / 应用集成
- 轻量数据分析

## 适合的项目

- **桌面 / 本地应用**：零运维
- **原型开发**：快速起步
- **数据分析中转**：临时库

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：SQLite 3.50.6、SQLiteStudio / DB Browser（可选）、better-sqlite3（Node）
- 注意：单文件数据库，适合本地应用与原型；高并发写入需谨慎

## 快速开始

```bash
sqlite3 app.db
sqlite3 app.db ".tables"
sqlite3 app.db "CREATE TABLE t(id INTEGER PRIMARY KEY, v TEXT)"
```
