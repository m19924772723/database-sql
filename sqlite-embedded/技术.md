# SQLite 嵌入式应用 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 引擎 | SQLite 3 | 嵌入式 |
| Node 驱动 | better-sqlite3 | 同步、快 |
| Python | sqlite3 标准库 | 开箱即用 |
| 检索 | FTS5 | 全文检索 |
| 工具 | DB Browser / SQLiteStudio | 可视管理 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **单文件模型**：一个文件即数据库
- **类型系统**：灵活类型与亲和性
- **FTS5**：全文检索与分词
- **并发**：WAL 模式提升并发

## 学习路径

1. 先用命令行建表查询
2. 再用语言 SDK 集成
3. 最后加 FTS5 与备份
