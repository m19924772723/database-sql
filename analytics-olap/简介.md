# 分析与 OLAP · 简介

> 面向分析场景的列式与 OLAP 数据库

## 能做什么

- 海量数据聚合分析
- 列式高速查询
- 直接查询文件
- BI 取数与指标
- 快速原型验证

## 适合的项目

- **数据分析**：大表聚合
- **日志分析**：海量日志
- **指标平台**：BI 取数

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：DuckDB / ClickHouse（需装）、Parquet、polars / pandas
- 注意：可直接查文件（Parquet / CSV），无需先导库

## 快速开始

```bash
pip install duckdb
duckdb -c "SELECT * FROM 'data.parquet' LIMIT 5"
# 或 SELECT * FROM read_csv_auto('data.csv')
```
