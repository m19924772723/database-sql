# 分析与 OLAP · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 列式分析 | DuckDB | 单机 OLAP |
| 分布式 OLAP | ClickHouse | 海量实时 |
| 文件格式 | Parquet / CSV | 列式存储 |
| 计算 | polars / pandas | 数据框 |
| 展示 | Superset / Metabase | BI 可视化 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **列式存储**：为什么分析更快
- **向量化执行**：批量计算
- **分区与排序键**：查询剪枝
- **与 Pandas 协作**：零拷贝交换

## 学习路径

1. 先用 DuckDB 查一个 Parquet
2. 再学聚合与窗口函数
3. 最后接 BI 展示
