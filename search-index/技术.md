# 检索与全文索引 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 轻量 | SQLite FTS5 | 零依赖 |
| 独立引擎 | Meilisearch | 开箱即用 |
| 分布式 | Elasticsearch | 海量检索 |
| 分词 | jieba / IK | 中文分词 |
| 建议 | 前缀索引 | 自动补全 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **倒排索引**：检索的核心结构
- **分词**：中文切分与词典
- **相关度**：TF-IDF / BM25 排序
- **索引更新**：增量与重建

## 学习路径

1. 先用 FTS5 做本地搜索
2. 再学分词与排序
3. 最后上独立引擎做规模检索
