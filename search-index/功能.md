# 检索与全文索引 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 索引

- **建索引**：文档入库
- **增量更新**：新文档即时可搜
- **重建**：全量刷新

## 检索

- **全文搜索**：关键词匹配
- **模糊匹配**：容错查询
- **高亮**：命中标注

## 分词

- **中文分词**：jieba / IK
- **自定义词典**：专有名词
- **同义词**：扩展召回

## 优化

- **排序**：相关度与业务权重
- **建议**：搜索联想
- **聚合**：分类统计

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
