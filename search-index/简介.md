# 检索与全文索引 · 简介

> 全文检索与索引服务

## 能做什么

- 全文搜索与模糊匹配
- 中文分词
- 聚合统计
- 搜索建议
- 增量索引

## 适合的项目

- **站内搜索**：内容检索
- **知识库检索**：文档查询
- **商品 / 文档搜索**：业务搜索

## 本机环境

- 本机状态：✅ 可直接开发（部分需装）
- 工具链：SQLite FTS5（已就绪）；Elasticsearch / Meilisearch（需装）、jieba（需装）
- 注意：轻量场景可用 SQLite FTS5，先跑通再上 ES

## 快速开始

```bash
pip install jieba
sqlite3 docs.db "CREATE VIRTUAL TABLE ft USING fts5(title, body)"
# 或起 Meilisearch 容器
```
